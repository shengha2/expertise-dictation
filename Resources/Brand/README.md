# Expertise Typer brand

`ExpertiseTyper.png` is the new master application icon: a warm-white typing cursor and voice waveform on a deep teal rounded square. Generated with the built-in image-generation tool, then mechanically resized and packaged into the macOS ICNS container by `scripts/make-icon.sh`.

The internal app identifier and data directories remain unchanged so existing permissions, dictionary entries and provider connections carry forward.
